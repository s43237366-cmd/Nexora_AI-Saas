01 / QUICKSTART

Install the SDK.

Initialize a Nexora client and send your first coding task in less than a minute.

terminal 
$ npm install @nexora/core
index.ts 
import { Nexora } from '@nexora/core';

const nx = new Nexora({
  apiKey: process.env.NEXORA_KEY
});

const result = await nx.agent.run({
  task: 'Add retry logic to checkout',
  context: './src'
});
02 / AUTHENTICATION

One key. Full control.

Use environment variables for server-side API keys. Never expose secret keys in browser code.

03 / AGENTS

Delegate the repetitive work.

Agents can inspect files, create patches, run tests and return a reviewable change set.

04 / CONTEXT API

Give the model the right context.

Attach repository paths, architecture notes and relevant documents to improve generation quality.

05 / ERRORS

Designed for debuggability.

Structured error codes and trace IDs make failures easy to identify in production.
