# Nexora Pro MultiPage

Static multi-page AI SaaS landing/promo website for DEVELOPER 2026.

## Pages
- index.html — Home
- features.html — Interactive Features tabs
- pricing.html — Pricing + live calculator
- docs.html — Developer Docs
- faq.html — Animated FAQ accordion

## Tech
- HTML5
- CSS3
- Vanilla JavaScript
- No Node.js
- No backend
- No API keys
- No build step

## GitHub Pages
1. Create a GitHub repository.
2. Upload the contents of this folder (not the ZIP itself).
3. Open Settings → Pages.
4. Under Build and deployment choose "Deploy from a branch".
5. Select branch `main` and folder `/ (root)`.
6. Save.
7. Open the generated Pages URL.

All internal links are relative, so the site works on GitHub Pages without server-side routing.

## Note
Nexora is a fictional/demo product concept. Email links use `hello@nexora.demo` as placeholder text.
